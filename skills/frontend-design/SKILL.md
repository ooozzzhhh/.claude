# Frontend Design Skill — 前端设计准则

使用本 skill 创建有独特风格、生产可用的前端界面。适用于构建网页组件、页面、原型、仪表盘、HTML/CSS 布局，或对任何 web UI 进行美化设计。

---

## 设计思考

编码前，先理解上下文并明确一个**大胆的审美方向**：

- **目的**：这个界面解决什么问题？谁在用？
- **基调**：选择一个极端方向：极简主义、最大化视觉密度、复古未来、有机自然、奢华精致、玩具感、编辑/杂志风格、粗野主义/原生态、装饰艺术/几何、柔和/粉彩、工业/实用主义等。从这些方向中汲取灵感，设计出真正符合项目语境的风格。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：这个界面最令人难忘的一点是什么？有什么是用户会一直记住的？

**关键原则**：选定一个清晰的概念方向并精准执行。大胆的最大化和精致的极简主义都行得通——关键在于有意识的选择，而不是设计强度本身。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），要求：
- 生产级别，功能完整
- 视觉醒目，令人印象深刻
- 风格统一，有明确的审美立场
- 每个细节都精心打磨

## 前端美学准则

重点关注以下方面：

- **排版**：选择美观、独特、有趣的字体。避免 Arial、Inter 等通用字体；选择能提升界面气质的个性字体，出人意料且富有个性的字体组合。将一个独特的展示字体与一个精致的正文字体搭配使用。

- **色彩与主题**：坚持统一的审美方案。使用 CSS 变量保持一致性。主色调搭配鲜明的强调色，优于平淡分散的配色方案。

- **动效**：使用动画实现视觉效果和微交互。HTML 中优先考虑纯 CSS 解决方案；React 中可使用 Motion 库。聚焦于高影响力的时刻：一次精心编排的页面加载（使用 animation-delay 实现交错显示）比分散的微交互更能带来愉悦感。使用令人惊喜的滚动触发和悬停状态。

- **空间构图**：出人意料的布局。非对称。重叠。对角线流动。突破网格的元素。大量留白或受控的信息密度。

- **背景与视觉细节**：创造氛围感和层次深度，而不是默认纯色背景。添加与整体审美相匹配的背景效果和纹理——渐变网格、噪点纹理、几何图案、多层透明度、戏剧性阴影、装饰性边框、自定义光标、颗粒感叠加。

**永远不要**使用这些通用的 AI 审美：Inter/Roboto/Arial 等过度使用的字体、陈词滥调的配色（尤其是白底紫色渐变）、可预见的布局和组件模式，以及缺乏具体语境特色的千篇一律的设计。

富有创意地诠释需求，做出真正为这个项目语境量身定制的意外之选。每个设计都不应该相同。在浅色与深色主题、不同字体、不同审美之间变换。**永远不要**在多次生成中趋向相同的常见选择（例如 Space Grotesk）。

**重要**：实现复杂度要与审美愿景相匹配。最大化设计需要包含大量动画和效果的精细代码；极简或精致的设计需要克制、精准，并对间距、排版和细微细节给予细心关注。优雅来自于对愿景的出色执行。

## B2B 供应链产品原型的特别说明

本项目的产品原型图（存放在 `产品设计/产品原型图/` 下）服务于 **B2B 供应链计划软件**，受众为业务用户和管理层。在应用上述设计准则时，应结合以下特点：

- **信息密度适中**：供应链软件通常数据量大，设计需平衡信息密度与可读性。
- **专业感**：商务/工业风格优先，避免过度娱乐化。
- **操作效率**：B2B 用户更注重效率，交互设计应减少不必要的步骤。
- **数据可视化**：计划数据（时间轴、甘特图、汇总表等）的可视化要清晰准确。

在满足以上约束的前提下，仍应追求有记忆点的设计，而不是千篇一律的「企业灰」。
