# 网页信息获取 Skill

按本 skill 执行网页信息抓取，确保操作规范、结束条件明确、存储结构清晰。

---

## 1. 工具与能力（Claude Code 环境）

在 Claude Code 中，使用内置的 **`WebFetch` 工具**获取网页内容：

| 工具 | 用途 |
|------|------|
| WebFetch | 获取指定 URL 的页面内容，自动将 HTML 转换为 Markdown 并由 AI 解析 |

**能力范围**：
- 支持静态 HTML 页面、服务端渲染页面、标准文档站
- 不支持：点击操作、滚动、JavaScript 动态渲染（SPA）、需登录的内容

**SPA 页面处理**：若目标页面（如 SAP Help Portal 部分页面）为 JS 动态渲染，`WebFetch` 可能只能获取骨架内容。此时须在摘要中注明「页面内容可能不完整」，并建议用户考虑：
- 寻找同内容的静态文档版本或 PDF 版本
- 手动复制页面内容并粘贴给 Agent

---

## 2. 工作流程

### 2.1 标准流程

1. **获取页面**：调用 `WebFetch(url, prompt)` 获取目标页面内容
2. **提取内容**：从返回结果中提取结构化信息（章节标题、正文、链接等）
3. **按指令操作**：若需要获取多个链接，从页面中识别目标链接，逐一获取
4. **汇总与存储**：按 [storage.md](storage.md) 写入 `info/` 目录
5. **返回摘要**：向主会话返回结构化摘要

### 2.2 多页面/多章节抓取

1. 先获取主页/目录页，识别各章节链接
2. 逐一使用 `WebFetch` 获取各章节页面
3. 每次获取后判断是否满足结束条件
4. 逐章提取内容，合并为结构化总结

---

## 3. 结束条件（强制）

**必须满足以下任一条件才能结束任务**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 数量限制 | 用户明确指定抓取数量 | 「抓取 2 个章节」「最多 5 页」 |
| 内容匹配 | 用户指定目标内容 | 「抓取与 MRP 相关的章节」 |
| 结构边界 | 页面结构天然边界 | 目录已到底、无更多链接 |
| 步数上限 | 防止无限循环 | 默认最多处理 10 个链接 |

**若用户未给出结束条件**：

1. **立即停止执行**，不开始抓取
2. **返回主会话**，提示用户补充：
   - 「请明确结束条件，例如：抓取 N 个章节、抓取到某关键词、或指定最大处理页数」
3. 主会话将提示转达给用户，待用户确认后再重新调度

---

## 4. 输出与存储

- **返回主会话**：结构化摘要（来源、章节列表、核心要点、存储路径）
- **写入 info 目录**：按 [storage.md](storage.md) 的目录与命名规则

详见 [storage.md](storage.md)。
